# 输出画幅判定（wh_ratio / ratio_follow）

> 用到才读：只在需要确定输出画幅时才打开本文件。判定完毕回 SKILL.md。

## 铁律

以下三条先站定：

1. `wh_ratio` 与 `ratio_follow` **互斥**——一个有值，另一个必须是空串 `""`。
2. `wh_ratio` 是 `"W:H"` 形式的**整数比**，例如 `"16:9"`。
3. **比例/分辨率永远不许写进 `rewritten_prompt`**，只由这两个字段传达。

**高分辨率关键词不是比例信号。** `2K` / `4K` / `8K` 只表达画质诉求，**不得**用来推断宽高比；宽高比仍按显式线索或输入图比例判定。输出分辨率一律按 2K 级给，与用户说的是 2K 还是 4K 无关。

---

## t2i 的默认比例

用户给了就用。没给则按主体朝向：

| 情形 | wh_ratio |
|---|---|
| 横向主体 | `3:2` |
| 纵向主体 | `2:3` |

这两个是默认值，覆盖大多数图像。特例：

| 情形 | wh_ratio |
|---|---|
| 方形徽章 / 图标 / 专辑封面 / 单个居中徽记 | `1:1` |
| 宽幅电影感或演示画面 | `16:9` |
| 手机屏幕 / 高立幅竖幅横幅 | `1:2` 或 `9:16` |

`3:4`、`2:1`、`21:9`、`4:3`、`9:21`、`4:5`、`3:1`、`5:4`、`1:3` 也存在，但**只有主体或用户真的需要时才用**。

> 比例判完要换算成具体宽高时，取值范围见 SKILL.md「画幅落地」：原生上限 `2048×2048`，默认 `1024×1024` 量级；**两个边长都必须取整到 32 的倍数**，否则会被悄悄改写。

## edit 判定 Step 1：用户有没有显式给尺寸或比例

在指令里找以下任一类：

- 精确像素：`1920x1080`、`800×600`、`1080p`
- 宽高比：`16:9`、`4:3`、`3:2`、`9:16`、`1:1`
- 描述词（见下表）

命中任一：

```
wh_ratio     = 对应比例（给了精确像素则化为最简整数比，1920:1080 → 16:9）
ratio_follow = ""
```

## edit 判定 Step 2：用户没给

### 单图编辑（N = 1）

默认输出跟随输入图：

```
wh_ratio = ""
ratio_follow = "<image1>"
```

**例外——单图场景生成。** 若任务是从零生成新场景、输入图只作身份参考（`拍一套写真`、`cosplay成X`、`穿越到古代`），则**不跟随输入图比例**——输出是新构图，不是对既有画面的编辑。按场景语义选 `wh_ratio`：

| 场景类型 | wh_ratio |
|---|---|
| Portrait / 写真 / 半身 | `2:3` |
| 全身场景 / 户外活动 | `3:4` |
| 横向场景 | `3:2` |
| 无明确朝向线索 | 跟随输入图（回到默认：`ratio_follow="<image1>"`，`wh_ratio=""`） |

### 多图编辑（N ≥ 2）

先认出**画布图**（构图与取景该被跟随的那张），再按编辑类型设置：

| 编辑类型 | 画布图是 | ratio_follow |
|---|---|---|
| 合成——主体迁入场景（`把A P到B中`、`放到`、`加入到`） | 目标场景图 | `<imageX>`（场景图序号） |
| 换脸 / 换头 | 身体图 | `<imageX>`（身体图序号） |
| 换衣服 / 换装 | 人物图 | `<imageX>`（人物图序号） |
| 风格迁移（`画成X的风格`） | **内容图**（不是风格参考图） | `<imageX>`（内容图序号） |
| 背景替换 | 前景主体图 | `<imageX>`（主体图序号） |
| 局部物体替换 | 正在被编辑的原图 | `<imageX>`（原图序号） |
| 场景生成——无画布（`合影`、`合照`、`一起变老`、`让他们X`） | 无画布，必须自选比例 | 见下表 |

**无画布的场景生成**（`合影`、`合照`、`一起吃饭` 等）：`ratio_follow=""`，按场景语义选：

| 场景类型 | wh_ratio |
|---|---|
| Group photo / 合影 / 合照 | `3:2` |
| Portrait / 写真 | `2:3` |
| Poster / 海报 | `2:3` |
| 电脑壁纸 | `16:9` |
| 手机壁纸 | `9:16` |
| 无明确朝向线索 | 跟随**最后一张**输入图（`ratio_follow` 设为最后一张，`wh_ratio=""`） |

> ⚠️ 经 ComfyUI-Roundabout 网关调用时有两条额外约束：① 多图编辑的输出实际**跟随第 1 个参考槽**，不是这里判出的 `<imageX>`——**画布图必须放在第 1 槽**，否则 `ratio_follow` 无法兑现；② 预裁画布图时**边长须取整到 32 的倍数**，否则会被悄悄改写。详见 SKILL.md「画幅落地」。

### 扩图 / outpainting

用户没给目标比例时，**不要简单跟随输入图比例**——扩图按定义就会改变比例。按延展方向推：

| 延展方向 | 新比例推断 | 例 |
|---|---|---|
| 只向右 / 只向左 | 变宽 | `1:1` → `3:2`；`3:4` → `1:1` 或 `4:3` |
| 左右都延 | 显著变宽 | `1:1` → `16:9` 或 `2:1` |
| 只向下 / 只向上 | 变高 | `1:1` → `2:3`；`16:9` → `4:3` 或 `1:1` |
| 上下都延 | 显著变高 | `1:1` → `9:16` |
| 四边都延 | 保持原比例 | 均匀长大 |

**通用估法**：延展方向额外加约 30%–50% 空间，再据此算新 W:H。设 `ratio_follow=""`、`wh_ratio=推断值`。

### 全景生成

| 全景类型 | wh_ratio |
|---|---|
| 标准全景 / 全景 | `2:1` |
| 超宽全景 | `3:1` |
| 360° / VR 全景 | `2:1` |
| 用户另行指定 | 用用户指定值 |

`ratio_follow = ""`。

### 三视图 / 多宫格

用户没给比例时**不要用固定默认值**，按三项自适应：

1. **主体形态比例**：站立的人偏纵向，车偏横向，圆形物体大致方形。
2. **面板排布**：如何排列（`1×3` 横排、`3×1` 竖排、`2×2`）及每格形状。
3. **合成比**：`(单格 W × 列数) : (单格 H × 行数)`，取最能容纳内容、不过度留白或裁切者。

实例：

- 站立人物的三视图并排（每格约 `1:3` 纵向）→ 整体 `1:1`。**不要**拉宽到 `2:1`/`3:1`，那会把每个纵向格压扁（只有每格本身是横向时才用 `3:1`，例如车）。
- 汽车三视图并排（每格约 `3:2`）→ 整体 `3:1` 或 `9:2`。
- 方形物体的 `2×2` 宫格 → 整体 `1:1`。
- 方形格的 `3×3` 宫格 → 整体 `1:1`。

设 `ratio_follow=""`、`wh_ratio=自适应值`。
